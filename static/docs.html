What this is

A single local API in front of small open models so other projects can hit one stable URL during development instead of burning hosted-API credits.

  • Text — llama.cpp (persistent llama-server): complete JSON or SSE token stream
  • Speech-to-text — whisper.cpp, spawned per request: complete transcript or SSE segments
  • Text-to-speech — Kokoro-82M, lazy-loaded in the hub: complete WAV or streamed WAV
  • Image — not implemented yet (returns 501)

Designed for a RAM-constrained, CPU-only box: the LLM stays warm (~2.5GB); STT loads on demand; Kokoro is lazy-loaded on first speak (~1GB) and reused.

How it runs

Two long-running processes. Start the LLM first, then the hub:

bash scripts/start_llm.sh    # terminal 1 — keep warm
bash scripts/start_hub.sh    # terminal 2 — API on :9000

The hub listens on http://localhost:9000. Interactive OpenAPI explorer: /docs.

Auth

Every /v1/... endpoint requires an API key with the matching scope (text, stt, tts, or image): 

Authorization: Bearer sk-hub-YOUR_KEY

Mint and revoke keys in the admin panel using HUB_ADMIN_TOKEN (treat it like a root password). The full key is shown once at creation; only a hash is stored.

Admin routes use the admin token, not an API key. Health is unauthenticated.

Health

GET /health no auth

Checks whether the persistent llama-server is reachable. STT is spawned per request; TTS is lazy-loaded in the hub.

curl https://sean.tail15fdf0.ts.net/health
import httpx

r = httpx.get("https://sean.tail15fdf0.ts.net/health")
print(r.json())
const r = await fetch("https://sean.tail15fdf0.ts.net/health");
console.log(await r.json());

Text generation

POST /v1/text/generate scope: text

Chat-style generation. Thin proxy to llama-server’s OpenAI-compatible /v1/chat/completions. Always returns a complete JSON body. Optional fields: max_tokens (default 512, max 4096), temperature (default 0.7). For tokens as they arrive, use /v1/text/generate/stream. 

curl -X POST https://sean.tail15fdf0.ts.net/v1/text/generate \
  -H "Authorization: Bearer sk-hub-YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [
      {"role": "user", "content": "Summarize what a Bloom filter is in 2 sentences."}
    ],
    "max_tokens": 512,
    "temperature": 0.7
  }'
import httpx

r = httpx.post(
    "https://sean.tail15fdf0.ts.net/v1/text/generate",
    headers={"Authorization": "Bearer sk-hub-YOUR_KEY"},
    json={
        "messages": [
            {
                "role": "user",
                "content": "Summarize what a Bloom filter is in 2 sentences.",
            }
        ],
        "max_tokens": 512,
        "temperature": 0.7,
    },
    timeout=120.0,
)
r.raise_for_status()
print(r.json())
const r = await fetch("https://sean.tail15fdf0.ts.net/v1/text/generate", {

Text generation (stream)

POST /v1/text/generate/stream scope: text

Same JSON body as /v1/text/generate. Proxies llama-server’s OpenAI-style SSE (text/event-stream). Use curl -N so the client does not buffer. Browser EventSource is GET-only — use fetch and read the body stream. 

curl -N -X POST https://sean.tail15fdf0.ts.net/v1/text/generate/stream \
  -H "Authorization: Bearer sk-hub-YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [
      {"role": "user", "content": "Summarize what a Bloom filter is in 2 sentences."}
    ],
    "max_tokens": 512,
    "temperature": 0.7
  }'
import json
import httpx

with httpx.stream(
    "POST",
    "https://sean.tail15fdf0.ts.net/v1/text/generate/stream",
    headers={"Authorization": "Bearer sk-hub-YOUR_KEY"},
    json={
        "messages": [
            {
                "role": "user",
                "content": "Summarize what a Bloom filter is in 2 sentences.",
            }
        ],
        "max_tokens": 512,
        "temperature": 0.7,
    },
    timeout=120.0,
) as r:
    r.raise_for_status()
    for line in r.iter_lines():
        if not line.startswith("data: "):
            continue
        payload = line[6:]
        if payload == "[DONE]":
            break
        delta = json.loads(payload)["choices"][0]["delta"]
        print(delta.get("content", ""), end="", flush=True)
const r = await fetch("https://sean.tail15fdf0.ts.net/v1/text/generate/stream", {
  method: "POST",
  headers: {
    "Authorization": "Bearer sk-hub-YOUR_KEY",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    messages: [
      { role: "user", content: "Summarize what a Bloom filter is in 2 sentences." },
    ],
    max_tokens: 512,
    temperature: 0.7,
  }),
});
if (!r.ok) throw new Error(await r.text());

const reader = r.body.getReader();
const decoder = new TextDecoder();
let buf = "";
while (true) {
  const { value, done } = await reader.read();
  if (done) break;
  buf += decoder.decode(value, { stream: true });
  const parts = buf.split("\n\n");
  buf = parts.pop();
  for (const part of parts) {
    const line = part.split("\n").find((l) => l.startsWith("data: "));
    if (!line) continue;
    const payload = line.slice(6);
    if (payload === "[DONE]") continue;
    const delta = JSON.parse(payload).choices[0].delta;
    if (delta.content) console.log(delta.content);
  }
}

Speech-to-text

POST /v1/audio/transcribe scope: stt

Multipart file upload. whisper.cpp expects 16 kHz mono WAV. Convert first if needed. For segments as they are decoded, use /v1/audio/transcribe/stream.

curl -X POST https://sean.tail15fdf0.ts.net/v1/audio/transcribe \
  -H "Authorization: Bearer sk-hub-YOUR_KEY" \
  -F "file=@input.wav"
import httpx

with open("input.wav", "rb") as f:
    r = httpx.post(
        "https://sean.tail15fdf0.ts.net/v1/audio/transcribe",
        headers={"Authorization": "Bearer sk-hub-YOUR_KEY"},
        files={"file": ("input.wav", f, "audio/wav")},
        timeout=60.0,
    )
r.raise_for_status()
print(r.json()["text"])
const form = new FormData();
form.append("file", wavFile); // a File / Blob of 16 kHz mono WAV

const r = await fetch("https://sean.tail15fdf0.ts.net/v1/audio/transcribe", {
  method: "POST",
  headers: { "Authorization": "Bearer sk-hub-YOUR_KEY" },
  body: form,
});
if (!r.ok) throw new Error(await r.text());
const { text } = await r.json();

Speech-to-text (stream)

POST /v1/audio/transcribe/stream scope: stt

Same 16 kHz mono WAV upload as /v1/audio/transcribe. Each whisper.cpp segment is an SSE event with done: false. The last event has done: true and the full concatenated transcript. 

curl -N -X POST https://sean.tail15fdf0.ts.net/v1/audio/transcribe/stream \
  -H "Authorization: Bearer sk-hub-YOUR_KEY" \
  -F "file=@input.wav"
import json
import httpx

with open("input.wav", "rb") as f:
    with httpx.stream(
        "POST",
        "https://sean.tail15fdf0.ts.net/v1/audio/transcribe/stream",
        headers={"Authorization": "Bearer sk-hub-YOUR_KEY"},
        files={"file": ("input.wav", f, "audio/wav")},
        timeout=60.0,
    ) as r:
        r.raise_for_status()
        for line in r.iter_lines():
            if not line.startswith("data: "):
                continue
            event = json.loads(line[6:])
            if event.get("error"):
                raise RuntimeError(event["error"])
            print(event["text"], flush=True)
            if event.get("done"):
                break
const form = new FormData();
form.append("file", wavFile); // a File / Blob of 16 kHz mono WAV

const r = await fetch("https://sean.tail15fdf0.ts.net/v1/audio/transcribe/stream", {
  method: "POST",
  headers: { "Authorization": "Bearer sk-hub-YOUR_KEY" },
  body: form,
});
if (!r.ok) throw new Error(await r.text());

const reader = r.body.getReader();
const decoder = new TextDecoder();
let buf = "";
while (true) {
  const { value, done } = await reader.read();
  if (done) break;
  buf += decoder.decode(value, { stream: true });
  const parts = buf.split("\n\n");
  buf = parts.pop();
  for (const part of parts) {
    const line = part.split("\n").find((l) => l.startsWith("data: "));
    if (!line) continue;
    const event = JSON.parse(line.slice(6));
    console.log(event.text, event.done);
  }
}

Text-to-speech

POST /v1/audio/speak scope: tts

Synthesizes speech with Kokoro-82M. Response body is a WAV file (audio/wav). Optional fields: voice (default af_heart) and speed (default 1.0).

curl -X POST https://sean.tail15fdf0.ts.net/v1/audio/speak \
  -H "Authorization: Bearer sk-hub-YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text": "Hello from your local model."}' \
  --output speech.wav
import httpx
from pathlib import Path

r = httpx.post(
    "https://sean.tail15fdf0.ts.net/v1/audio/speak",
    headers={"Authorization": "Bearer sk-hub-YOUR_KEY"},
    json={"text": "Hello from your local model."},
    timeout=60.0,
)
r.raise_for_status()
Path("speech.wav").write_bytes(r.content)
const r = await fetch("https://sean.tail15fdf0.ts.net/v1/audio/speak", {
  method: "POST",
  headers: {
    "Authorization": "Bearer sk-hub-YOUR_KEY",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ text: "Hello from your local model." }),
});
if (!r.ok) throw new Error(await r.text());

const blob = await r.blob();
const url = URL.createObjectURL(blob);
const audio = new Audio(url);
audio.play();
// or: download — const a = document.createElement("a"); a.href = url; a.download = "speech.wav"; a.click();

Success is a binary WAV, not JSON. On failure you get a JSON error body. For audio as it is synthesized, use /v1/audio/speak/stream.

Text-to-speech (stream)

POST /v1/audio/speak/stream scope: tts

Same JSON body as /v1/audio/speak (text, optional voice / speed). Response is a streaming WAV (16-bit PCM mono, 24 kHz): a header, then audio chunks as Kokoro finishes each phrase. 

curl -N -X POST https://sean.tail15fdf0.ts.net/v1/audio/speak/stream \
  -H "Authorization: Bearer sk-hub-YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text": "Hello from your local model."}' \
  --output speech.wav
import httpx
from pathlib import Path

with httpx.stream(
    "POST",
    "https://sean.tail15fdf0.ts.net/v1/audio/speak/stream",
    headers={"Authorization": "Bearer sk-hub-YOUR_KEY"},
    json={"text": "Hello from your local model."},
    timeout=60.0,
) as r:
    r.raise_for_status()
    with Path("speech.wav").open("wb") as out:
        for chunk in r.iter_bytes():
            out.write(chunk)
const r = await fetch("https://sean.tail15fdf0.ts.net/v1/audio/speak/stream", {
  method: "POST",
  headers: {
    "Authorization": "Bearer sk-hub-YOUR_KEY",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ text: "Hello from your local model." }),
});
if (!r.ok) throw new Error(await r.text());

const chunks = [];
const reader = r.body.getReader();
while (true) {
  const { value, done } = await reader.read();
  if (done) break;
  chunks.push(value);
}
const blob = new Blob(chunks, { type: "audio/wav" });
const url = URL.createObjectURL(blob);
const audio = new Audio(url);
audio.play();

Success is a binary WAV stream, not JSON. Players that need a known file size in the WAV header may wait until the stream ends.

Admin keys

Use the admin panel in a browser, or call these routes with HUB_ADMIN_TOKEN. Anyone with that token can mint or revoke keys.

POST /admin/keys admin token

Create a key. Scopes: text, stt, tts, image. expires_in_days is 1–3650. The full key is returned only this once.

curl -X POST https://sean.tail15fdf0.ts.net/admin/keys \
  -H "Authorization: Bearer $HUB_ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "eventer-dev",
    "scopes": ["text", "stt"],
    "expires_in_days": 30
  }'
import os
import httpx

r = httpx.post(
    "https://sean.tail15fdf0.ts.net/admin/keys",
    headers={"Authorization": f"Bearer {os.environ['HUB_ADMIN_TOKEN']}"},
    json={
        "name": "eventer-dev",
        "scopes": ["text", "stt"],
        "expires_in_days": 30,
    },
)
r.raise_for_status()
print(r.json()["api_key"])  # save now — shown only once
const r = await fetch("https://sean.tail15fdf0.ts.net/admin/keys", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${adminToken}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    name: "eventer-dev",
    scopes: ["text", "stt"],
    expires_in_days: 30,
  }),
});
const data = await r.json();
console.log(data.api_key); // save now — shown only once
